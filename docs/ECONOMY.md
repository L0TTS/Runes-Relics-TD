## Вероятности выпадения реликвий

Статус: формула из [«Формул и статов» в Notion](https://living-metal-4f5.notion.site/40e8416afec480af89a5c1ca37169f15). Детали уточняются по [Q-12](QUESTIONS.md#q-12-экономика-и-магазин).

| Редкость | Шанс до корректировки |
| --- | --- |
| Обычная | 50% |
| Магическая | 30% + удача / 100 |
| Редкая | 15% + удача / 100 |
| Легендарная | 5% + удача / 100 |

По описанию, избыток сверх 100% вычитается из шанса наименее редкой категории. При удаче 2000 в источнике приведены исходные шансы 50%, 50%, 35%, 25%, а после корректировки — 0%, 30%, 35%, 25%. Последние в сумме дают 90%. Порядок корректировки нужно уточнить. В [концепте](CONCEPT.md) высшая редкость называется «уникальной».
